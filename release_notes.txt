## Breaking Changes

- Default Detach now requires the 3DS:ATLAS module; install and enable it alongside Default Detach or the module will not load.

## New Features

- 3DS:ATLAS adds update notices, a built-in troubleshooter, and shared theming for Default Detach's windows.

## Changes

- The configuration dialog picks up 3DS:ATLAS theme colors.
- Updated the bug-report form's example versions to Foundry 14.364 and dnd5e 6.0.0.
- Updated the Default Detach Discord invite link on the issue tracker's contact link.
